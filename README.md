# Vocabulary Trainer

Vocabulary Trainer — небольшой PET-проект для изучения и закрепления словарного запаса иностранного языка с особым вниманием к правильному написанию слов (орфографии).

Идея проекта — сделать изучение слов более осознанным и измеримым: не просто проверять, помнишь ли ты перевод слова, но и оценивать, насколько уверенно можешь самостоятельно его воспроизвести без орфографических ошибок.

Программа сочетает несколько подходов к проверке знаний, ведёт историю тестирований, анализирует результаты и адаптирует подбор слов с учётом предыдущих ошибок.

## 🎯 Основные возможности

1. Проверка словарного запаса и орфографии

Программа показывает слово на русском языке, а пользователь должен самостоятельно написать его перевод на английском.

Оценка ответа производится по следующему принципу:

Для длинных слов допускается больше орфографических ошибок. Это позволяет оценивать результат более справедливо: одна ошибка в коротком слове и одна ошибка в длинном слове — не совсем одно и то же.

По результатам тестирования рассчитываются два независимых показателя:

Знание слов — насколько хорошо пользователь знает и может воспроизвести изучаемый словарный запас.  
Знание орфографии — насколько правильно пользователь умеет писать слова.

Таким образом, можно знать слово, понимать его значение и даже уверенно воспроизводить его, но при этом допускать ошибки в написании. Программа учитывает эту разницу.

2. Быстрое тестирование на распознавание слов

Дополнительный режим проверки знаний — тестирование на скорость.

Программа показывает английское слово, после чего пользователь должен в течение 5 секунд выбрать правильный перевод на русском языке из шести предложенных вариантов.

Особенности режима:

Ограничение времени на ответ — 5 секунд.  
Один правильный вариант из шести.  
Проверка скорости распознавания и понимания слов.  
Результаты сохраняются отдельно и доступны на специальной странице.  

Этот режим позволяет проверить не только способность вспомнить слово самостоятельно, но и скорость его распознавания.

3. История тестирований и статистика

Каждое завершённое тестирование сохраняется в журнале.

Это позволяет:

Просматривать результаты предыдущих тестов.
Отслеживать динамику изучения словарного запаса.
Оценивать прогресс по знанию слов и орфографии.
Анализировать результаты отдельных слов.
Видеть, какие слова вызывают наибольшие затруднения.

Вместо субъективного ощущения «кажется, я уже знаю эти слова» пользователь получает измеримые показатели прогресса.

## 📊 Система оценки знаний

В проекте используется несколько независимых показателей, позволяющих оценить состояние словарного запаса.

Основные показатели
Показатель	Описание
Слов в словаре	Общее количество слов в базе
Освоено слов	Количество слов, которые пользователь уверенно знает, даже если допускает орфографические ошибки
Освоено без ошибок	Количество слов, которые пользователь воспроизводит правильно, без ошибок
Успешность воспроизведения	Общая эффективность ответов с учётом всех попыток
Критерии освоения слова

Для определения того, действительно ли слово усвоено, анализируются последние три попытки ответа по нему.

Освоено слов:

Последние три попытки должны иметь оценку 1 или 2 балла.
Допускаются орфографические ошибки, если слово в целом воспроизводится правильно.

Освоено без ошибок:

Все последние три попытки должны иметь оценку 2 балла.
Слово должно воспроизводиться без орфографических ошибок.

Такой подход позволяет отличать простое узнавание слова от действительно устойчивого знания.

## 🧠 Адаптивный подбор слов

Одна из важных особенностей проекта — программа не выбирает слова полностью случайным образом.

При формировании теста учитываются два фактора:

1. Частотность употребления слова

Каждому слову присваивается вес в зависимости от распространённости в языке:

Вес	Значение
3	Наиболее распространённые слова
2	Слова средней распространённости
1	Редкие слова

Чем выше вес слова, тем чаще оно появляется в тестах.

Это позволяет уделять больше внимания наиболее полезной и востребованной части словарного запаса.

2. Коэффициент забывания

Дополнительно учитывается история ответов пользователя.

Если слово было написано с ошибками или пользователь не смог вспомнить его перевод, программа повышает приоритет этого слова при последующих тестированиях.

Таким образом:

Хорошо освоенные слова постепенно встречаются реже.
Слова, в которых допускались ошибки, появляются чаще.
Забытые или плохо усвоенные слова получают повышенный приоритет.

В результате формируется адаптивная система повторения, которая концентрирует внимание на проблемных местах, а не заставляет пользователя постоянно повторять уже хорошо знакомые слова.

## 💾 Хранение данных

Для хранения словарного запаса используется формат JSON.

Это осознанное архитектурное решение для небольшого персонального проекта.

Почему JSON:

Не требуется устанавливать и настраивать СУБД.
Не нужно поддерживать отдельный сервер базы данных.
Словарь легко редактировать и расширять.
Данные удобно переносить между компьютерами.
При небольшом объёме информации производительности вполне достаточно.

Для персонального приложения с относительно небольшой нагрузкой это простой и практичный вариант.

История тестирований также сохраняется, что позволяет анализировать прогресс во времени.

## 🛠️ Цели проекта

Проект создавался прежде всего для личного использования, как практический инструмент изучения иностранного языка.

В процессе разработки хотелось реализовать не просто очередной словарь или тест на знание перевода, а небольшую систему, которая:

Помогает расширять активный словарный запас.
Учит правильно писать иностранные слова.
Разделяет знание слова и знание его орфографии.
Учитывает частотность употребления слов.
Адаптируется к результатам предыдущих тестирований.
Позволяет объективно отслеживать прогресс обучения.

## 📝 Заключение

Vocabulary Trainer — небольшой эксперимент на стыке изучения иностранных языков, анализа статистики и алгоритмов адаптивного обучения.

Главная идея проекта проста: важно не просто однажды правильно ответить на вопрос, а научиться стабильно воспроизводить слово без ошибок.

А программа должна помогать понять, какие слова уже действительно освоены, а какие ещё требуют внимания.
